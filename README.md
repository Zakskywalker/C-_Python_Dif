# C# / Python Reference & DSA Matrix

An interactive, single-file reference for comparing C#/.NET and Python. The page pairs examples side by side, with shared search, section filters, copyable code, a linked sitemap, and print controls.

## Open the reference

Open [`index.html`](./index.html) in a modern web browser. It runs locally and does not require a server, package installation, or network access.

## What's inside

- **Project setup and source files:** CLI setup, entry points, classic `public static void Main(string[] args)`, Python `main(argv)`, multi-class/multi-file examples, models, services, tests, JSON, and project metadata.
- **Language fundamentals:** types, strings, slicing, control flow, pattern matching, functions, generators, object-oriented patterns, collections, and LINQ/comprehensions.
- **Files and concurrency:** resource management, file I/O, async/await, and concurrent operations.
- **Data structures and algorithms:** queues, stacks, deques, heaps, matrices, linked lists, binary search trees, tree traversals, graph BFS/DFS, shortest paths, tries, union-find, and common algorithm patterns including sliding windows, prefix sums, sorting, and dynamic programming.
- **Using/import API trees:** practical, paired indexes of common .NET namespaces and Python modules, with representative callables and short descriptions. These are selected reference lists, not exhaustive catalogs of every API.
- **Sitemap and flashcards:** a clickable graph connecting matching language sections and searchable cards about concepts and language differences.

## Search and navigation

- Enter a term in the search box to find matching titles, descriptions, code, APIs, source files, or flashcards.
- Choose a section using the navigation buttons. Choose **ALL SECTIONS** to clear the section filter.
- Use the scope selector to narrow results by snippet, method, class/module, script, or CLI.
- Use **RESET** to clear the search and filters.
- Use **COPY_CODE** to copy an individual example.
- In the flashcards section, select a question to reveal or hide its answer.
- In the sitemap, select a node to jump to the corresponding comparison section.

## Printing

Choose a print mode before selecting **PRINT_DOCUMENT**:

- **ALL SECTIONS** prints the complete reference.
- **SELECTED SECTIONS** prints the sections selected in the adjacent multi-select control.
- **CURRENT VIEW** prints results currently visible under the section, search, and scope filters.

Choose **COLOR** or **BLACK & WHITE** to control the print stylesheet. The layout preserves the two-column C#/Python comparison and follows the paper orientation selected in the browser's print dialog. For color backgrounds, enable **Background graphics** in that dialog if needed.

## Notes

- Examples are intended as quick references; check the target framework, Python version, and project/package dependencies before using them in a specific project.
- Some snippets are methods or classes intended to be placed into a project rather than run as standalone files.
- The reference is intentionally local and self-contained. To update it, edit the HTML file directly.
